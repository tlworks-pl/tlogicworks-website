# Folder zdjęć i logo — T-LogicWorks

Wrzuć tutaj pliki graficzne, a strona automatycznie je załaduje.

## Logo
- `logo.svg` — logo wektorowe (zalecane) LUB `logo.png` (min. 200×60 px, tło przezroczyste)

## Zdjęcia
- `hero.jpg` — zdjęcie do sekcji głównej (hero), format 16:9, min. **1600×900 px**
- `about.jpg` — zdjęcie do sekcji "O Firmie", format 4:5, min. **900×1120 px**

## Wskazówki
- Użyj formatu `.jpg` dla zdjęć, `.svg` lub `.webp` dla logo
- Kompresuj zdjęcia (np. przez https://squoosh.app) — zalecane < 500 KB każde
- Nazwa pliku **musi być dokładnie taka jak powyżej** (małe litery, bez polskich znaków)
